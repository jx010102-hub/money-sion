# 가계부 앱 설치 방법

## 1. 인터넷 주소 만들기 (GitHub Pages, 무료, 한 번만)

홈 화면 앱으로 쓰려면 파일을 웹에 올려야 해요. PC에서 하면 편하지만 아이패드 Safari로도 할 수 있어요.

1. https://github.com 에 가입하고 로그인합니다.
2. 오른쪽 위 **＋ → New repository**를 누릅니다.
   - Repository name: `gagyebu` (원하는 이름)
   - **Public** 선택 → **Create repository**
3. 생성된 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 압축을 푼 파일 6개(`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`)를 올리고 **Commit changes**를 누릅니다.
5. 저장소의 **Settings → Pages**로 갑니다.
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더: **/(root)** → **Save**
6. 1–2분 기다리면 `https://jx010102-hub.github.io/money-sion/` 주소가 생깁니다.

> 저장소는 공개지만, **지출 기록은 아이패드 안에만 저장**되고 GitHub에는 올라가지 않아요. 올라가는 건 앱 화면 파일뿐이에요.

## 2. 아이패드 홈 화면에 설치

1. 아이패드 **Safari**로 위 주소를 엽니다.
2. 주소창 옆 **공유 버튼(□↑) → 홈 화면에 추가 → 추가**를 누릅니다.
3. 이제부터는 홈 화면의 **가계부** 아이콘으로만 여세요.
   (Safari에서 연 것과 홈 화면 앱은 저장 공간이 따로라서, 기록이 서로 보이지 않아요.)

## 3. 매일 알림 + 월말 요약 알림 (단축어)

앱의 **설정** 탭에도 같은 안내가 있어요.

1. **단축어** 앱 → **자동화** 탭 → **＋**
2. **특정 시간** → 오후 9:00 (원하는 시간) → **매일** → **즉시 실행** → 다음
3. **새로운 빈 자동화** → 동작 **알림 보기** → `오늘 지출을 입력하세요 ✍️`
4. 동작 추가: **현재 날짜** → **날짜에 더하기**(1일) → **날짜 포맷**(사용자 지정 형식 `d`)
5. 동작 추가: **만약(If)** — 포맷된 날짜 **이(가)** `1` 일 때 → **알림 보기**
   `이번 달 마감! 가계부에서 한 달 요약을 확인하고 엑셀로 공유하세요 📊`
6. 완료

4–5번은 "내일이 1일이면 오늘이 말일"이라는 계산이라, 달마다 말일이 달라도 자동으로 맞춰져요.

## 4. 월말에 엑셀 보내기

**내보내기** 탭 → 달 선택 → **엑셀 공유** → 공유 창에서 **카카오톡**(나와의 채팅 등) 또는 **메일** 선택.
시트는 *지출내역 / 카테고리별 / 결제수단별 / 일별* 4개로 구성돼요.

## 5. 백업 (꼭 가끔 해 주세요)

**내보내기 → 백업 파일 저장**을 누르면 `.json` 파일이 만들어져요. '파일' 앱이나 iCloud Drive에 저장해 두세요.
앱을 지웠다가 다시 설치했을 때 **백업 파일에서 복원**으로 되살릴 수 있어요.

## 앱을 고친 뒤 업데이트하려면

GitHub 저장소에 바뀐 `index.html`을 다시 올리면 돼요. 다음에 앱을 열 때 자동으로 새 버전이 적용되고, 기록은 그대로 남아요.
