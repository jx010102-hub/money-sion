결제수단

매일 알림 · 월말 요약 알림 설정 (단축어)

아이패드 기본 앱 ‘단축어’로 한 번만 설정하면 돼요.

  1. 단축어 앱 → 아래 자동화 탭 → ＋ (또는 ‘새로운 자동화’)
  2. 특정 시간 선택 → 시간(예: 오후 9:00) → 매일 → 즉시 실행 선택 → 다음
  3. ‘새로운 빈 자동화’ → 동작 추가에서 알림 보기 검색 → 내용: 오늘 지출을 입력하세요 ✍️
  4. (월말 요약) 동작 추가 → 현재 날짜 → 날짜에 더하기/빼기: 1일 더하기 → 날짜 포맷: 사용자 지정 d
  5. 만약(If) → ‘포맷된 날짜’ 이(가) 1 → 그 안에 알림 보기: 이번 달 마감! 가계부에서 한 달 요약을 확인하고 엑셀로 공유하세요 📊
  6. 완료. 알림이 오면 홈 화면의 가계부 아이콘을 눌러 입력하세요.

4–5번은 ‘내일이 1일이면 = 오늘이 말일’이라는 뜻이라, 28·30·31일로 끝나는 달 모두 자동으로 맞춰져요.
